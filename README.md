🎓 CGPA Calculator

A responsive and user-friendly CGPA & GPA Calculator built using HTML, CSS, and JavaScript. This application helps students calculate semester-wise GPA and overall CGPA quickly and accurately through an intuitive interface.

🚀 Features

📚 Semester-wise GPA calculation

🎯 Overall CGPA calculation

📝 Subject code, subject name, and credit management

🎓 Grade selection using dropdown menus

📊 Automatic GPA and CGPA calculation

💯 Calculates total credits and earned credits

📱 Responsive design for desktop and mobile devices

⚡ Fast and lightweight with no external dependencies

🛠️ Technologies Used

HTML5

CSS3

JavaScript (ES6)

✨ Functionalities

Add subjects for each semester.

Enter subject code, subject name, and credits.

Select grades from the dropdown menu.

Calculate Semester GPA instantly.

Enter semester GPA values to calculate Overall CGPA.

View total credits, earned credits, GPA, and CGPA.

🎯 Future Enhancements

Save GPA/CGPA using Local Storage

Export results as PDF

Print mark sheet

Dark Mode support

Support for multiple university regulations

Student profile management
